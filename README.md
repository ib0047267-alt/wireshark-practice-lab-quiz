# Wireshark Network Analysis Labs and Quizzes

## Project Overview
This project documents my practical learning experience with **Wireshark**, a network protocol analyser, using the practice labs and quizzes provided by **NetworkWalks**.

The goal was to develop practical skills in packet capture, network traffic analysis, protocol identification, and basic security investigation.

## Labs and Exercises Completed

I worked through the eight Wireshark practice labs, covering:

- **Lab 1 – Packet Capture:** Capturing network traffic and identifying IP addresses, DNS servers, website IP addresses, server ports, and TLS versions.
- **Lab 2 – PCAP Analysis:** Analysing previously captured network traffic.
- **Lab 3 – Identify the Attacker's IP:** Investigating traffic to identify a suspicious source IP.
- **Labs 4 & 5 – Follow TCP Stream:** Reconstructing and examining TCP communication.
- **Lab 6 – HTTP Plain Text Credentials:** Understanding the risks of transmitting credentials over unencrypted HTTP.
- **Lab 7 – Brute Force Investigation:** Identifying repeated login attempts.
- **Lab 8 – Call Scammer Investigation:** Analysing network evidence to investigate suspicious activity.

I also completed the **Basic Wireshark Quiz** and **Advanced Wireshark Quiz** to assess my understanding.

## Skills and Knowledge Gained

- Capturing and analysing network packets.
- Understanding TCP, DNS, HTTP, TLS, ICMP and other protocols.
- Using Wireshark display filters.
- Identifying source and destination IP addresses.
- Following TCP streams to inspect network conversations.
- Recognising suspicious traffic patterns.
- Understanding the security risks of plaintext communication.

## Challenges Faced and How I Overcame Them

During the exercises, I encountered some difficulties:

- **Understanding packet details:** At first, identifying useful information from captured packets was challenging. I improved by examining the Packet Details pane and expanding protocol layers.
- **Using display filters:** I initially found it difficult to remember the correct filter expressions. Repeated practice helped me become more familiar with filters such as `dns`, `http`, `icmp`, and `ip.addr`.
- **Analysing TCP streams:** Reconstructing network conversations required careful examination. I used the Follow TCP Stream feature to understand the communication.
- **Identifying suspicious traffic:** Some investigations required comparing packet patterns and source addresses. Working through the lab instructions helped me understand how to approach these cases.

## Conclusion

Completing these labs and quizzes improved my understanding of network communication and packet analysis. This experience has strengthened my foundation in networking and cybersecurity, particularly in network traffic investigation and blue-team security operations.

This project is part of my continuous learning journey in cybersecurity.
